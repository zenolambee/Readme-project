# OpenCode Commands

Gunakan perintah ini saat ingin membuka atau menghapus konfigurasi OpenCode.

```bash
nano ~/.config/opencode/opencode.json
rm ~/.config/opencode/opencode.json
```

## Notes

- Perintah `nano` digunakan untuk mengedit file konfigurasi.
- Perintah `rm` digunakan untuk menghapus file konfigurasi bila perlu.
